# Changelog

## 0.5.1

- Publish one-command installers for macOS/Linux and Windows PowerShell.
- Detect `Spine.com` and `Spine.exe` across standard Windows install locations.
- Test Python 3.10–3.13 on macOS, Windows, and Linux in GitHub Actions.

## 0.5.0

- Add `gpt-spine` production CLI and complete `build_workflow` MCP tool.
- Add OpenAI Agents SDK stdio MCP client and Codex setup instructions.
- Add macOS, Windows, and Linux Spine CLI auto-detection with `SPINE_BIN` override.
- Add true rig-only mode, clean quad meshes, single-bone auto-weighting, IK,
  clipping, multi-state animation generation, and slot animation presets.
- Add semantic validation, `rig_report.json`, preview directory, cross-platform
  installers, tests, and macOS/Windows/Linux CI.

## 0.1.0

- Preserve the upstream `spine-mcp` rigging, atlas, preview, and CLI wrappers.
